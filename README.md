# pi-patterns

Small, self-contained Pi patterns.

## Patterns

### [`nested-subagents`](patterns/nested-subagents)

Minimal nested-subagents demo with depth protection (`orchestrator` → `worker`).

See its [README](patterns/nested-subagents/README.md) for install + usage.

### [`subagent-question`](patterns/subagent-question)

Subagents ask questions that ripple up through nested levels to the orchestrator (`delegator` → `asker`), configured via agent definitions.

See its [README](patterns/subagent-question/README.md) for install + usage.
